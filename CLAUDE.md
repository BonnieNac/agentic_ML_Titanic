# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

Dependency/environment management is via [uv](https://docs.astral.sh/uv/) — never use `pip` directly.

```bash
uv sync                                    # install/sync deps into .venv (downloads a Python interpreter if needed)
uv run python main.py                      # run the full pipeline: load -> train -> evaluate -> save
uv run pytest                              # run all tests
uv run pytest tests/test_train.py::test_train_model_fits_and_splits_data  # run a single test
uv run ruff format .                       # format
uv run ruff check .                        # lint
uv run ruff check --fix .                  # lint with autofix
```

## Architecture

Linear pipeline, orchestrated by `main.py`, with one module per stage under `src/`:

`src/data.py` (`load_data`) → `src/preprocess.py` (`split_features_target`) → `src/train.py` (`train_model`, `save_model`) → `src/evaluate.py` (`evaluate_model`)

- **`src/preprocess.py`** is the contract for the whole pipeline: `FEATURES` (= `NUMERIC_FEATURES + CATEGORICAL_FEATURES`) and `TARGET` define which columns are used everywhere downstream. Add a feature by editing these lists — `build_preprocessor()` picks it up automatically via `ColumnTransformer`.
- **`src/train.py`**'s `build_model()` returns a single scikit-learn `Pipeline` combining the preprocessor and a `RandomForestClassifier`; `train_model()` does the train/test split (stratified) and a 5-fold CV on the training set only, then fits on the full training set. It returns `(model, X_test, y_test)` — the held-out test set is not touched until `evaluate_model`.
- **`src/data.py`** caches the dataset at `data/titanic.csv` (downloaded from a fixed GitHub raw URL on first run); subsequent runs skip the download if the file exists.
- Trained artifacts (`models/titanic_model.joblib`, `models/confusion_matrix.png`) and `data/*.csv` are git-ignored and regenerated by running `main.py`.
- `[tool.uv] package = false` in `pyproject.toml` — this is an application, not an installable package; `src` is imported directly (works because `pythonpath = ["."]` is set for pytest, and scripts are run from the project root via `uv run`).

## Testing conventions

Tests never hit the network or read the real dataset. `tests/conftest.py` provides a `titanic_df` fixture (60-row synthetic DataFrame shaped like the real dataset, including some missing `Age`/`Embarked` values). `tests/test_data.py` monkeypatches `src.data.DATA_DIR`/`DATA_PATH`/`urlretrieve` to test the download-vs-cache branches in isolation.
